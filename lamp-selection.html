第二步：用 INKNOT 核心约束条件逐一淘汰
⬇
✖ 约束 ① ：必须人机共存——抽屉打开、滑盖透明时，光对客户零伤害 淘汰 A、B
✗ 传统 UVC 254nm — 致癌、灼伤眼角膜，必须完全密闭，滑盖透明会漏光
✗ UVC LED 265-280nm — 同属 UVC 波段，对人体有害，必须联锁断电
✓ Far-UVC 222nm — 穿透力仅到皮肤角质层死细胞，不伤活细胞，IEC 62471 认证人机共存
✓ 蓝光 405nm — 完全无害，可常年常亮
⬇
✖ 约束 ② ：以"维持洁净"为主功能，但必须具备真正的杀菌能力（不能是装饰灯） 淘汰 D
✓ Far-UVC 222nm — 与 254nm 同机制（破坏 DNA/RNA），秒级灭活
✗ 蓝光 405nm — 靠激发细菌内卟啉产生活性氧，杀菌需数十分钟至数小时，速度慢，实际效果弱

蓝光在纹身场景下不适用：工具包取出前不可能等几小时。蓝光多用于医院墙壁/食品工厂的连续背景照明，不适合封闭小仓的快速维护。

核心逻辑：INKNOT 的 UV 洁净仓需要人机共存 + 真正杀菌 + 视觉可见三者同时满足。
传统 UVC（含 LED）虽杀菌强但不安全 → 淘汰。
蓝光虽安全但杀菌太慢，更像"氛围灯" → 淘汰。
Far-UVC 222nm 是唯一同时通过两项约束的技术。

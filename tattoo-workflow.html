纹身全流程图

Tattoo Workflow Map — 为 INKNOT 纹身工具台设计提供工作流参考 · 从咨询到愈合的完整链路

1 咨询与设计 · 30–60 min

工具

iPad / 绘图板 设计软件 (Procreate) 参考图库 皮肤记号笔 转印纸 测量尺 咨询表

耗材

转印膏 / 转印液 皮肤消毒液 一次性剃毛刀

流程步骤

  • 与客户沟通图案需求、风格、尺寸、位置
  • 评估皮肤状况（疤痕、痣、皮肤类型）
  • 签署知情同意书
  • 设计或调整图案（手绘 / 数字）
  • 将图案转印至转印纸
  • 备皮 剃毛 → 消毒 → 转印图案到皮肤
  • 客户确认位置与大小
2 环境与工具准备 · 15–20 min

工具

纹身机 (线圈/马达) 电源供应器 脚踏开关 针具 (各类针型) 手柄 / 握把 色料杯 / 墨杯 色料瓶

耗材

一次性针具 一次性手套 一次性色料杯 机器保护套 / 隔离袋 工作台保护膜 纸巾 / 蓝卷纸

流程步骤

  • 工作台覆保鲜膜 / 隔离膜
  • 纹身机装保护套（隔离袋）
  • 针具从灭菌包装中取出并安装
  • 色料倒入一次性色料杯
  • 电源、脚踏线缆整理
  • 消毒 所有接触面二次消毒
  • 洗手 + 戴上一次性手套
3 割线 · 30–90 min

工具

纹身机 (割线用) RL 割线针 (Round Liner) 黑色色料 凡士林 喷雾瓶 (绿皂水)

流程步骤

  • 沿转印线走线，控制深度 (1–2mm 真皮层)
  • 持续擦拭多余色料与血液
  • 涂抹凡士林保持皮肤润滑
  • 绿色皂液喷雾清洁表面
  • 卫生 每接触非无菌物后换手套
4 打雾 / 上色 · 1–4 hr

工具

纹身机 (打雾用) RS/M 打雾针 (Round Shader / Magnum) 各色色料 稀释液 凡士林

流程步骤

  • 换针 → 换色料杯 → 按色块区域逐步填充
  • 由深到浅或由浅到深（取决于风格）
  • 不同针型切换：M1 (窄 magnum) → M2 (宽 magnum)
  • 白点高光提亮（部分风格）
  • 持续清洁 + 润滑表面
5 清洁与包扎 · 5–10 min

工具

绿色皂液 / 专用清洁液 无菌纱布 修复膏 / 凡士林 医用胶带 / 修复膜 (Derm Shield) 一次性手套

流程步骤

  • 绿色皂液彻底清洁纹身区域
  • 无菌纱布轻拍干燥
  • 薄涂一层专用修复膏或凡士林
  • 覆盖修复膜 (如 Saniderm / Derm Shield)
  • 告知客户后续护理方法
6 器械回收与消毒 · 10–15 min

工具

超声波清洗机 高温高压灭菌器 (Autoclave) 酶清洗液 消毒浸泡盘 灭菌包装袋 利器回收盒 (Sharps Container)

流程步骤

  • 安全 废弃针头丢入利器回收盒
  • 一次性耗材 (手套/色料杯/保护膜) 丢弃
  • 纹身机手柄、握把拆解 → 酶液浸泡
  • 超声波清洗机清洗可复用器械
  • 干燥 → 封装灭菌袋 → 高温高压灭菌
  • 工作台面全面消毒擦拭
  • 灭菌记录登记 (spore test 定期检测)
7 客户术后护理 · 2–4 周愈合期

客户需备

修复膏 / 专用护理霜 无香型温和皂 修复膜 (替换用) 防晒霜 (SPF 50+)

客户须知

  • 24h 后揭除首层修复膜，温水冲洗
  • 每日 2–3 次温和清洁 + 薄涂修复膏
  • 避免浸泡 (泳池/浴缸/桑拿) 2–4 周
  • 避免阳光直射，出门涂 SPF 50+
  • 结痂期间不抓挠，自然脱落
  • 4–6 周后回店复查，必要时免费补色

核心工具清单

纹身机— 线圈机 (传统) / 马达机 (静音、可调)
电源供应器— 稳压供电，控制机器速度 & 力度
脚踏开关— 控制纹身机启停
针具— RL (割线) / RS (打雾) / M1-M2 (Magnum 大面积)
色料— 黑色 (割线) + 各色 (打雾上色)
转印纸 + 转印液— 将图案转印到皮肤
凡士林— 术中润滑，减少皮肤损伤
绿色皂液— 术中清洁、术后清洗
修复膜 (Derm Shield)— 术后覆盖保护创口
超声波清洗机— 清洗可复用器械
高温高压灭菌器— Autoclave，医疗器械灭菌标配
利器回收盒— 废弃针头安全回收
一次性手套— 全程使用，接触污染后立即更换
工作台保护膜— 隔离工作台面与污染源
机器保护套— 隔离纹身机与血液/色料
